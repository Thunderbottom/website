A note is short writing: a thought, a link worth keeping, something half-formed.
It is shown in full in the list, so there is no need to click through to read it.

Markdown works as usual: **bold**, _italics_, `code`, [links](https://example.com),
lists, quotes and fenced code blocks. Rename the file to `.mdx` to also use
sidenotes and message boxes, as in posts (see `example-post.mdx`).
